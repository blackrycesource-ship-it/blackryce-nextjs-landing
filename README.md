# Black Ryce Landing Page

Single-page Black Ryce marketing website built with Next.js and Tailwind CSS.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Where to edit content

Most placeholder content is in `src/data/site.js`.

The page sections are in `src/app/page.js` and the navigation is in `src/components/Navbar.jsx`.

Replace `public/logo.png` when the final logo file is available.
